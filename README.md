# صدى (Sada) — الإصدار ٢

غرف صوتية وفيديو ومكالمات بين الأصدقاء، فوق **Metered**، مع **حسابات حقيقية** (اسم مستخدم وكلمة مرور) وقائمة أصدقاء.

```
server/   خادم Node بلا اعتماديات تقريباً (مكتبة pg فقط للتخزين الدائم)
client/   React + Vite، واجهة عربية RTL
```

## ما الجديد
- تسجيل حساب ودخول. كلمات المرور تُخزَّن مشفّرة (scrypt)، والجلسة توكن موقّع صالح ٩٠ يوماً.
- أصدقاء: إرسال طلب باسم المستخدم، قبول/رفض/حذف، وشارة بعدد الطلبات.
- الخصوصية تُفرض في الخادم: غرفة «أصدقائي» يدخلها أصدقاء المضيف فقط، و«بدعوة» تُفتح بالرابط فقط.
- المكالمات المباشرة للأصدقاء فقط، مع رفض ومهلة ٤٥ ثانية.
- الاسم الظاهر يأتي من الحساب في الخادم، فلا يمكن انتحال اسم شخص آخر.
- تحديد معدل محاولات الدخول (٨ محاولات كل ١٠ دقائق لكل اسم وعنوان).

## التشغيل المحلي
```bash
cp server/.env.example server/.env     # ضع METERED_APP_NAME و METERED_SECRET_KEY
npm run install:all
npm run dev                            # الخادم :8787 والواجهة :5173
npm --prefix server test               # اختبارات الخادم مع Metered وهمي
```

## النشر على Railway
1. **Build:** `npm run install:all && npm run build` — **Start:** `npm start`
2. **المتغيرات:** `METERED_APP_NAME` و `METERED_SECRET_KEY`.
3. **التخزين الدائم (مهم):** أضف قاعدة **PostgreSQL** من Railway، ثم في خدمة sada أضف المتغير
   `DATABASE_URL` بالقيمة `${{Postgres.DATABASE_URL}}`.
   بدونها يعمل التطبيق، لكن الحسابات والأصدقاء **تُمسح عند كل نشر جديد**.
4. تحقق: افتح `/api/health` في المتصفح، يجب أن ترى `"storage":"postgres"`.

## حدود معروفة
- **لم يُجرَّب مع Metered حقيقي من بيئة التطوير هنا.** الاختبارات تستخدم نسخة وهمية من واجهة Metered.
  كذلك كود Postgres وبناء الواجهة (Vite) لم يُشغَّلا هنا لعدم وجود إنترنت.
- لا إشعارات دفع: المكالمة الواردة تظهر والتطبيق مفتوح فقط.
- الصوت قد ينقطع عند تصغير التطبيق (قيد أندرويد على الميكروفون في الخلفية).
- المنصة (من يتحدث) تُفرض من الواجهة فقط؛ للتشديد استخدم `ownerOnlyBroadcast` في Metered.
- لا استعادة كلمة المرور (يحتاج بريداً إلكترونياً) ولا حذف حساب بعد.
- الغرف والحضور في ذاكرة الخادم: إعادة تشغيله تُنهي الغرف الجارية (الحسابات تبقى مع Postgres).
